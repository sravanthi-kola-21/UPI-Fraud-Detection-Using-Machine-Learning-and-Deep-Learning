# UPI Fraud Detection Using Machine Learning and Deep Learning

Built a real-time fraud detection system for UPI transactions.

**Tech Stack:** Python, Flask, Machine Learning, Deep Learning, SQL

**Key Features:**
- Built Flask REST API for real-time fraud prediction
- Trained ML/DL models on transaction data
- API ready for frontend integration

**How to run:**
1. Install requirements: pip install -r requirements.txt
2. Run: python app.py
